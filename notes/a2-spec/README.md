## Decided while writing the spec
- **Tickets go whole**, not cut to an offer: a grant by a holder's writers is the holder's own data, so its nodes learn it by syncing the holder; a grant from outside is itself the `grant@~0` fire on the holder, which tells the holder the thing exists and carries the boxes and `sync.0` (the offer is that message, nothing more). The ticket reference kind, its CBOR tag, `tickets.0`, the account's tickets, `ticket@~0`, key-change tickets, fetching on a ticket's word, and removal notices (`removal@~0`: a removal reaches the holder's nodes through the target they sync or hold for keys) are gone. For Tess: spec/requirements.md Concepts ("a **ticket** also carries what is needed to sync its target") and Offline ("shared only by granting a role and handing over a ticket") name the removed concept; no property breaks (sharing is a grant plus the grantee's own strong). Her wording change.
- **Box delivery stays where it must**: a rotation or re-seal boxing a holder that cannot open it from the target's own sync ID (sync alone, re-sealed) goes to the holder's sync ID as a *sealed copy* (a certificate copy sealed like a fire, promoted iff in the holder's key part, bound by no setting). This is the edge piece placed where it belongs, not a notification, but it is the one remaining push into a sync ID the sender does not sync.
- **Takenness** is judged by the holder's readers from a path the role commit states for the holder (spec/wire.md §4 Holders: one `Path` covers it, else a `Split` entry; a `Split` is now allowed on role commits), or a held `grant@~0` fire valid by the current setting whoever fired it (so a writer's fire takes nothing by authority: no accepting). A link redemption is a grant from outside the redeemer's account.
- **Interim placement until A4**: an account's key part is under its account root D's sync ID, and what reaches it from outside under its inbox's. The account's creation keeps `grant@~0` for good.
- **Chained writes go**: evidence takes every edge write on a stated path's edges (write-path-design §2 E1); re-grant already reads "made by right".
- **Role changes travel** keeps keys-open travel (a role commit naming H in the required set of each sync ID whose thing's keys open H), as finding 19 requires; the holder-side half is the key part.
