# Sync rebuild handoff
> Summary: Where the sync rewrite stands and how to continue it: the local integration branch sync-rebuild, the brief preamble every Phase 3 agent reads, and the queue of open items. Delete when the rebuild lands on main.

The rewrite (issues/sync-rewrite.md) is on the local branch `sync-rebuild`, never pushed. It only moves forward: module branches fast-forward it, and main comes in by `git merge origin/main`. Every module is built and reviewed there, and nodes of two accounts sync end to end. Left: the items below, then a final integration review, one `tools/gate.sh` on sync-rebuild, a fast-forward of main, and the dogfood rebuild.
