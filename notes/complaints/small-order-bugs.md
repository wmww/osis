- The order harness's `alike` has no access to the held set or `played`; a tolerance that needs a delivery (here `flips`) had to be threaded in as a closure through every caller.
- Reviewer: `OSIS_CRDT_SEED=n cargo test -p osis-crdt -- --include-ignored` runs osis-crdt's dev-profile timing tests (`budget_big_text_spec_6`, one thread, 18+ min before I killed it); the crdt "tier 2" oracles (`*_large`, `paging_large`) need `--skip budget --skip hostile_moves --skip shrink_script --skip same_stamp_substitution`. The ignored set mixes timing budgets with oracles; notes/testing.md's periodic form omits the ignored ones entirely.
