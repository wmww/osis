# tomb-all
- A node runs local passes (and so drops anything locally) only after `publish_reach`: a test of a local drop without it silently tests nothing (no drop happens).
- Lost-answer tests are easily non-discriminating: a second right holder online deletes the host copy by its own normal path, and an expiring commit's linked blobs expire at the host too. Check each new test fails with the fix disabled.
- A certificate copy whose commit expires within a few seconds goes relay-only at a host (code 7): such a copy never reaches it.
