# sheave-c11-rejudge
- `growth::flat_work` (read's work per round no more late than early) has had no running caller since R1 deleted the grant arms; its one caller is ignored on issues/storage-owners.md. Main's grant rounds grew from 530 to 834 judgements per round over ten rounds (unchanged re-runs 109 to 258) with nothing failing. A work-flatness check should not ride on a storage-audit test that can be ignored for an unrelated leak: `read::a_new_sync_id_judges_nothing_again_under_the_others` now guards the same cost on its own.
- The rounds' counters reset per round (`round_work` calls `costs::take`), so a `take` around `grant_rounds` reads only the last round and the settle tail; the first totals I took were that. A note on `one_and_ten`/`round_work` saying so would have saved a measuring pass.
