# keyset-names
- TLC's `MC_names_own` sized like `MC_fork_reorder` took 1M states (57 s on 4 workers) to fail; withholding the removal from a2 and no write cut it to 14 s on 1 worker. A negative control is cheapest built on the withholding instance, not the any-order one.
- `cargo build --workspace --tests` after an osis-keys change took over 120 s and was moved to the background mid-call; start such builds in the background from the outset.
- The any-order (`InOrder = FALSE`) withholding instance never finished (5M+ distinct states, growing); an hour went to waiting before switching it to log order with the host's log skipping the removal (2.9M states, 19 min at load 50). `MC_grant_remove` alone took 60 min at that load: `run.sh all rotation` is a periodic-sized job, not a per-branch one.
- Review: `run.sh` checks only that a negative control fails, not on which invariant; I read the TLC logs by hand (`TLC_KEEP_LOGS`) to see `DepartedLocked`/`DevLocked`. An expected invariant name in the instance line would make that automatic.
- Review: `osis-keys` `names::` differential runs in 0.01 s at the config's 32 proptest cases; as a per-branch oracle for an establishment change it is thin (try `PROPTEST_CASES=4096`).
- Fix round: TLC exploded (500k+ states, not finishing in minutes) because the new group actions ranged over `Nodes`, which includes the group node itself; restricting them to `Admins`/`Withhold` and dropping the write cut the positive instance to 24k states. A model action over `Nodes` is worth a second look for the passive nodes.
- Fix round: the extended model's first positive run failed on a third hole (issues/unestablished-successor-history.md) unrelated to the names rule; splitting the instance by invariant (`DevLocked` without writes vs `DevNoLeak` with one) kept the names result checkable.
- Review 2: the forge harness in rotation tests needed a hand-built keyset and `ActorEpochs` to probe a new forger path (no helper takes "forger holds admin via path P"); a `Forger` variant per path is cheap but each probe re-derives D's epoch by hand.
- frozen-coverage: `tools/bin-at` checks REV out in the worktree while it builds; a parallel agent (the TLA fork) editing files there sees them flip to REV's content for ~2.5 min. Never run bin-at while another agent shares the worktree.
- frozen-coverage: the node test helper `remove_holder` built removals whose rotation named nothing; any rule reading names treats those as unaware rotations. Hand-made rotations in test helpers drift from the engine's; prefer engine flows.
- frozen-coverage: tier 1 took ~9 min wall at load 31-37 (machine shared).
