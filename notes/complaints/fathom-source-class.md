# fathom-source-class
- spec_map anchors: a test comment's `§N (name: ...)` must quote text of that section before the colon; a free paraphrase fails `--gaps --uncited` as a stray anchor. Easy to miss until the tool runs.
- A World test of a three-node grant history costs about 3 s; a scripted `Pair` covers the arrival-order part in milliseconds.
- Review: a test Bash call whose command was denied (it carried a `git stash list`) silently skipped the file edit chained before it; the next run looked like a real failure.
