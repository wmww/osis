# prose-testing
- tools/limits.py parses its limit tables out of notes/build.md (NOTE path): a prose edit that moves or reshapes the Time limits tables breaks every limit check. Kept them in build.md; a moved table needs limits.py's NOTE changed too.
- About 140 pointers into testing.md/build.md across code comments, tools, issues and notes; a regex pass by section name did most, but bare "notes/testing.md" ones need reading one by one. Pointers to sections that had never existed were already there ("long aspect table", "Commit floor (below)" in crdt.md, `Net::group` seeding note naming the gone `group_seeded`).
- The repoint script's skip pattern for my own new notes (`notes/test-[a-z]+`) also skipped notes/test-design.md; caught by a heading check afterwards. A heading-existence check over every `notes/X.md, Section` pointer is cheap and found the misses.
- tools/bin-at's header says an interrupted build is fixed by deleting the newest incremental dirs; notes/build.md (Footguns) says that left the bad rlib in place and `cargo clean -p <crate>` is the fix. Left the tool comment alone; one of them is wrong.
