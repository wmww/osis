# history-less-grant complaints
- A field added to `ct::Edge` (and `osis_perm::Edge`, `Recipient`) breaks ~300 struct literals across crates, frozen sync tests and sim included; fixed mechanically from compiler error positions (a script inserting the field). A constructor (`Edge::role(r)`) used by tests would have kept it to a few lines.
- Planted-fault runs mutate files in the worktree; a second edit or `cargo check` while one runs races it. Run them only with the tree otherwise idle.
- A bash variable not exported (`S=...; python3 - <<EOF` reading `os.environ['S']`) half-applied a scripted edit; read paths from argv.
- `git checkout -- file` to undo a planted fault also drops the uncommitted fix in that file: commit before planting.
- Review: the planted-fault table was not re-run after the second round; a fault outside the model (a writer's `keys.0` body re-writing another's epoch's floor) leaked pre-cut secrets with every listed test green. Keyset-level state any writer can re-write needs its own hostile test, not just the model's mutation table.
- Review: an icount old-vs-new comparison needs the old tree's test binary; `git checkout <base> -- core cli schema`, build, copy the binary aside, `git checkout HEAD -- ...` worked without a second worktree (one rebuild each way).
- Round 3: engine newcomer tests fed the newcomer plaintext packages filtered by a "before the cut" set, which can never show what a sealed label hands it (wraps, sections, the epoch a body was placed under). `LocalPeer::sealed` exists; a `Label` that seals each commit when it is first placed was needed to see the stall and the inbox gap. Sealing everything at the end hides them: it seals under the newest epoch.
- Round 3: the full Cut.tla run.sh grew to ~10 min at one worker once `X_floor_any` ran with a merge allowed; sizing each new run.sh instance by hand first (16 workers under heavy) would have saved a run.
- Round 3: a scripted fix of 7-argument calls left `(&x).to_vec()`/`(&y).clone()` forms clippy rejects; write the cleaned form in the script.
- Round 3: my own planted-fault script restored each file with `git checkout --`, which also dropped that file's uncommitted fix (three files): exactly the footgun noted above. Restore from a copy taken before the edit, or commit first.
- Review round 2: the newcomer tests checked secrets and the roster only; sealing every content section and wrap under the roles secret passed all 21 `tests_cut` tests. A content key in the randomized test catches it now. Every planted fault on a crypto layer should be checked against what the user reads, not only the secrets held.
- Review round 2: `Label` places each commit once, right after it is made, so no test ever encrypted an old commit again after a cut; that path (and compaction) hands the newcomer pre-cut content. A harness that only seals at first placement hides every re-encryption path.
