# review-rot-oracle
- The claimed worktree came with a stale `git bisect` in progress (another task's, from an earlier claim): `wt claim` does not clear it, and a bisect state in a reused worktree can mislead `git status` and later git commands. Cleared with `git bisect reset HEAD`.
- A hand world built to exercise the oracle passed under both old and new oracles at first: the box to the holder actor was a blind one, forgiven by `excused` before the changed clause was reached. Worth knowing when writing oracle tests here: make the rotator a reader of the holder actor.
