# regrant-drop
- The trace (`OSIS_SYNC_TRACE=1:t0`) hid the cause: a place reset that misses a source not yet loaded leaves no frame or store change. A probe test printing store state per step found it in one run; worth a harness helper (per-step state dump for one node and one thing).
- Rebasing onto a just-merged integration branch: `git rebase --onto sync-rebuild duties-security` failed because the merged branch was already deleted; the old tip's hash had to come from the log.
- (review) A world test of "start finds S read with its drop mark" can't use hand delivery: the read module logs hand-delivered commits under S itself (`Store::log` ignores the mark), so the copy comes back either way and the mutation passes. The stale mark's real effects (refused stamped takes, deposits and Deletes at a read S; no from-start refetch) need a crash between taking the grant and `pull_anew`'s transaction, which only a ~120-write crash sweep (~60 s) reaches.
