# held-set-full
- `OSIS_ORDER_SHRINK=1` keeps any failure, so a shrink slides to another symptom (5021's signal validity shrank to a role-commit mismatch, 5022's settled read to a validity one). Read the shrunk failure line, not the seed's.
- A full-size plain seed replays in 5 s but shrinks in 3-9 min; shrink all failing seeds at once in the background.
- `pkill -f <test name>` matches the Bash tool's own command line and kills the shell.
- A Parts-away start at the history's beginning can be voided by later steps (a removal with an earlier frontier, a required setting refusing `Mixed`), and an aimed tail lands on things whose creation the fresh nodes lack; the start works once every peer is given it.
