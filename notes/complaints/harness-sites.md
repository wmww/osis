# harness-sites
- `packages_to` (a world copy and a sync per call) or `packages_to_peer` (deliveries to a copy) in a per-seed or per-order loop costs as much as the test's own deliveries: first conversions put +3% on the touched modules' instructions. A fresh reader's list is its sync set plus its thing's sync IDs (`common::packages_reading`), an observer's is its own sync set (`packages_for_peer`), and one reader's list serves every reader of a thing: no copy needed.
- A fresh reader's sync set as it stands misses its thing until it holds the record: `packages_for` to one silently dropped a commit the test then found missing.
- `memory::big_map_apply_memory` (by hand) failed on main: its child node was a bare node keeping none of the thing's content. By-hand tests rot unseen; nothing runs them.
- A blanket `sed` over a file's calls also rewrote three calls that were not mine; diff against the base before testing.
