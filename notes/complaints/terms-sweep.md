# terms-sweep
- `grep` here is ugrep: `grep -o -E '.{0,110}(a|b).{0,110}'` fails with "exceeds complexity limits". Used a small Python keyword-in-context script.
- spec_map RULES pin exact sentence text, so a prose rename of a MUST sentence fails `--gaps` unless tools/ changes too; a docs-only sweep has to leave those words.
- Line-numbered sweeps need the line numbers taken after any edit that adds lines (notes/ephemeral.md grew by two).
