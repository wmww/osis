# Complaints: a2-model
> Summary: Footguns met cutting held-model `closure::keys` to taken grants and building the joint property (A2 brief 0, second cut).

- A check built from the world's paths alone hid a control: the joint property's `J-act` enumerated only paths the world still has, so a node acting on a removed hop it believed standing was never tried. Candidates must include what the node under test believes, not only the oracle's view.
- `paths::World::lowers` counts a fresh grant of write as a lowering (anything below admin); for "removals" use `evidence::World::removes`. Using `lowers` for a control made it fail for the wrong reason.
- A slice small enough for a default test reaches the common controls but not one that needs a removal on a second path: that control needed its own hand world.
