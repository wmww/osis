# a2-derive
- held-model `evidence` writes a commit's parts as one event each (`write_parts`), so a step can hold one part of a two-holder removal while the closure reads the commit's other parts off the world: an adapter feeding held parts only disagreed on 3 of 150 random worlds until it gave each held copy every part of its commit on that thing.
- `tools/mutate.py` with a multi-line OLD prints its table row across lines: a script taking the last `|` line got the row's tail, not the failing tests; read `MUTATE_OUT`'s logs instead.
- A `tools/heavy --short` run stopped once past the lane's CPU-s is refused in the lane for good, even after the property was cut to fit: run the resized command in a hold once.
