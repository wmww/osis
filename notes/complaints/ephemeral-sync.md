# ephemeral-sync
- Generated schema fixtures (core/schema/tests/gen/*.rs) cannot be regenerated with `OSIS_REGEN_VECTORS=1` once they reference a removed type (the test binary includes them and no longer compiles): hand-edit the offending line first, then regenerate.
- osis-node test `Net::advance` ticks nodes before it delivers queued closes: after `restart_server` (or anything queuing `Close`), a node only notices the drop inside the advance, so its redial waits for the next one. Call `net.run()` first.
- Changing the blob prefix length shifted blob IDs and exposed a pre-existing proto bug (replay cursor position above 2^63 replayed a page twice): a fixed-seed test had only ever seen IDs below 0x80.
- (reviewer) osis-node `Net`: the `note`/`eph_write` helpers feed `Event::Local` straight to the sync engine, even for a node set offline; its dials then connect while `feed` drops the `Up`, the connection hangs forever and the node never redials. Offline writes must go through `engine().write` and `net.run()`. Cost an hour chasing a fake divergence in the randomized differential.
- (reviewer) The 30-seed sweep took 611 s (notes/build.md: 2.2 min); `stranded_reseal` 8112 alone ran minutes before failing with a message storm. Comparing against main needed three detached builds in the worktree (main, two branch commits), about 20 s each; fine, but `sim-sweep --only X --from S --seeds 1` with a relative binary path silently printed nothing when run from another dir (my mistake, grep hid the error).
- (security fixes) A test loop "upload until refused" never ends once eviction at the total cap keeps the uploader's own label under its cap: bound such loops. A backgrounded `cargo test` stuck in it looked like a slow build for 5 minutes.
- (security fixes) `compact_ephemeral` returns a cover the caller must place: a test that only called it deleted the covered entries at the server (the next eph_step forgets and deletes what was dropped) without sending the cover, and a restarted reader then saw nothing. `SyncEngine::compact_ephemeral_now` (doc-hidden) places it.
- Final reviewer: edited a test file while a background oracle chain was still compiling; the chain's `work_sets_match_full_passes` step failed to compile on the half-done edit and had to be rerun. Do not edit sources while a chain that still builds is running.
- Final reviewer: `random_window_converges_large` failures print only "no quiescence after 200000 messages" with no seed; finding the seed took a per-seed xargs run of the copied binary. The run now prints its log when nobody holds the window; a seed in the quiescence panic would help too.
- re-review of c80278f9: the 2-server random window test hides single-server liveness bugs (the uncapped server carries everything); added a one-capped-server variant. Bash tool's 180 s move-to-background made a foreground seed loop land in a task file.
