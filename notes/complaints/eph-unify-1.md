# eph-unify-1
- A holder refusing an ephemeral commit for its node cap (`EphIngest::TooLarge`) is silent in node tests: two tests diverged and it took ad-hoc eprintlns in engine and node-sync to see the cap was the cause. A test helper listing a node's diagnostics (or a debug log of refusals) would have shown it at once.
- Follow-up (trigger fix): weighing parts by the full holder charge (decoded heap twice) made covers come too late for small server caps (`server_cap_compaction_frees_it`); only the per-part overhead term is shared. `restarted_cover_waits_for_every_label` counted entries that existed only because a cover happened to have fired: setup checks should assert the property, not counts tied to cover timing. Oracles ran at load 65 (10 min for the three random_window tests).
