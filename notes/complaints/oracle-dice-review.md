# oracle-dice-review
- A foreground 180 s move hit sabotage matrix builds twice: start anything with more than a quick build under `run_in_background`.
- `cargo test --no-run --message-format=json` lists sim-sweep's executable too: pick `/deps/it-` or `tail -1` takes the wrong binary.
- Sabotages too blunt to tell (a missed trigger for good) fail the sim's quiescence checks; a delayed trigger is what tests a comparison of times.
- `OSIS_SIM_ONLY=` set empty selects no scenario and passes (0 runs): read the `N runs` line.
