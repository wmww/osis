# mizzen-stale-names
- A `rate:` known-failure line is never flagged stale (KNOWN-BUT-PASSED skips rate lines), so one whose seed passes on main stays until someone replays it by hand: held-model-until-no-deadline's did. Replaying each rate line's seed at a landing would catch them.
- `tools/heavy` waited 20 minutes for a 9-second run (80 CPU-s); it said afterwards the short lane fitted. Nothing tells a caller beforehand which lane a property replay needs.
- An ignored repro can pass by commit-ID luck (removal-not-logged-first's), so "its repro passes" is no evidence the issue is gone; a repro of an order rule wants its world picked so the wrong order is the one the IDs give.
