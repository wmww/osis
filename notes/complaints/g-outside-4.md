# g-outside-4
- `cargo test -p a --test it -p b ...` applies `--test it` to every package: crates without an `it` target, and every lib's unit tests, silently do not run. Name `--test it` per run or run lib tests apart.
- A fresh reader seeded 1 inside a `net(3, 0)` world is Bob's account (seeds `s*1000+i`): the grant re-granted Bob and a removal test read as if the removal failed. Nothing warns of a seed collision.
- The engine's `Misuse("the secrets it derives from are not held")` from `grant` meant the grantee's account chain was not held: the message names the wrong thing.
- osis-sync's differential and sims compare against `harness::history::reference`, a bare engine handed every commit: under the outside-the-closure rule it holds no content, so every content check there fails at once (7 tests); no engine-crate run shows it.
