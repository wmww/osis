# order-write-perm
- The order harness prints only the error of a refused sync (`no permission to write T`), not which local write inside the receive failed; finding `settle_none` took a temporary backtrace at every `Error::Permission` site. A Local error escaping a receive could carry its site.
- `OSIS_ORDER_SHRINK=1` on this seed took about 8 min for a 60-step history; the shrunk history still carries the whole settling tail (about 300 steps), so it is not hand-readable.
- Building an engine-level reproducer took several tries: a replacer's own cover drops both bodies at the replacer at once, so its later packages carry no parts (`missing`), which reads like a delivery bug. `keep_bodies(true)` at the replacer is the way to hand out uncovered bodies.
- Review: `answer_rotations` runs at every transaction's end outside a step, so its errors fail receives (issues/rotation-answer-fails-receive.md); the end-of-transaction writers have no one rule for "own optional write never fails a receive".
