# addenda-wake complaints
> Summary: Workflow snags met while redesigning addenda's wake.

- notes/perm-paths.md and notes/build.md print as single 300-600 character lines per bullet: a plain `cat` or `grep` of either overflows the tool output, so reading them takes `cut -c` passes.
- The old wake's doc and notes/engine-roles.md argued a member joining a named holder moves what a removal gathers; under stated paths it does not (the gathering reads R's edge histories and deltas stated through R's edges only). Notes describing an input set should be re-derived from `gather` when the model changes, not carried.
