- `RUSTC_BOOTSTRAP=1 cargo test ... -Z unstable-options --report-time` (to see per-test times) changes cargo's fingerprint and rebuilds the crate: a second copy of the artifacts. There is no stable way to see which default test is slow; a `--report-time` note in notes/build.md would save the detour.
