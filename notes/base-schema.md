# osis-base and osis-schema surfaces
> Summary: The public surface of the two crates everything builds on: osis-base (Value and its ordering, canonical CBOR and decode bounds, ids and creation records, the owner-chain walk, time, `format` constants, chunker, hashing and text codecs, error classes, `testenv`, the integration-test layout rule) and osis-schema (types, schemas, typed access, diff view, keys, core types, codegen). Crate map and rules: notes/architecture.md; schema evolution: notes/versioning.md; the DSL and data model reasons: notes/data-model.md.

## osis-base
- `Value`: `Int(i64)`, `Float(Float)`, `Bool`, `Str(String)`, `Bytes(Vec<u8>)`, `Tid(Tid)`, `Enum(u64, Option<Box<Value>>)`, `Map(ValueMap)` (also structs: int keys), `List(Vec<Value>)`, `Set(ValueSet)`, `Link(Box<Link>)`, `Unknown(Box<Unknown>)`, 32 bytes. `ValueMap`/`ValueSet` are sorted vectors (collect, not random-order insert, for a big one). Enum case IDs are u64 (CBOR uint). `Value::float(f64)`, `depth()` (arrays, maps and tags on the deepest path; a scalar is 0).
- **Order rule**: `Ord` is computed structurally and equals bytewise order of canonical encodings (proptest-checked), so maps and sets hold canonical order and uniqueness by construction. Exception: `Eq`/`Ord`/`Hash` compare a `Link` by content hash only (spec/data-model.md §4, §6: two writes of one large value are equal; canonical order is unchanged since the hash leads); the decoder rejects a set or map holding two links of one hash (`EqualLinks`). So `Ord` matches byte order only for values without such links, and `encode` sorts the encodings of a set or map that holds a link. Compare `Link` structs when exact identity matters.
- **Decode memory**: at most about 56 B per input byte for any input, with no picked limit: every item is at least a byte, so the heads' promised items may not exceed the input (`Decoder::promise`; only invalid input is refused). A path decoding a blob twice frees the first decode first (`InboxPayload::split`). `cbor::Reader` reads items one at a time for callers that cannot pay for a whole decode of hostile bytes.
- `Float`: bit pattern; `new` normalizes NaN, `from_bits` rejects other NaNs. `Unknown::new(tag, CanonicalBytes)` refuses tags this build knows (`is_known_tag`); the reserved STRUCT tag counts as unknown. An unknown CBOR tag is no error: it decodes to `Value::Unknown`, and parking happens where a typed read fails.
- `cbor`: `encode`, `encode_into`, `decode(&[u8], &Limits)` (whole input; `Limits.max_depth` counts as `depth()`), `decode_prefix` (the value and the bytes it spans), `item_prefix` (one item's bytes by its heads alone, nothing decoded: for bytes verified by hash), `visit_items` (heads only), `Limits { max_depth, max_bytes }` (`Limits::DEFAULT` from `format`), `DecodeError` (always BadInput; one variant per rule), `CanonicalBytes` (bytes proven canonical: `parse`, `from_value`, `as_bytes`, `to_value`, `depth`). `head(out, major, arg)`, `head_len(arg)`, `MAJOR_*`: canonical item heads for callers that splice pre-encoded items (osis-commit's commit blobs, osis-label's large strings). Recursive with a depth cap; claimed lengths are checked against remaining input before allocating.
- Ids: `Tid` (15 bytes; `from_bytes`, `as_bytes`, `of_record`, `Display`/`parse`/`FromStr` 20-char base64url, `to_uri` with `osis://`); `CreationRecord::{Thing { owner, nonce }, KeyActor { alg, public_key, nonce }, Ownerless { admin, nonce }}` with `to_value`/`from_value`/`tid`/`owner` (spec/wire.md §3; `from_value` accepts only `alg` = `SIGNING_KEY_ED25519` (1) with a 32-byte key); `Ak` (`new` parses the grammar of spec/data-model.md §2 within `format::MAX_AK_BYTES`; `const fn check` for key constants; `segments`, `version`, `tid`, `admin`, `lifetime`, `markers_of`, `successor_of`); `Lifetime` (`Durable`, `Ephemeral`, `Signal`); `PurgeBy` (the purgeable-by set, `admin`/`author`/`writer` membership); `Link { hash, blob, suite, key }` (`Debug` hides the key); `BlobId`/`CommitId` (32 bytes), `LabelId` (16 bytes) as public-field newtypes; `Role` (Read < Write < Admin).
- `owner_chain` (`chain.rs`: `Owner`, `ChainStep`, `OwnerChain`): every walk up creation records goes through it, so the stop rules and `MAX_OWNER_DEPTH` live in one place.
- Time: `Time(u64)` (wall ms; `WallMs` is the same type under the name the layers below the API use), `Ts` (`make(wall, logical)`, `from_u64`, `to_u64`, `wall_ms`, `logical`), `Clock` (`now_wall_ms`; `Send + Sync`), `ManualClock` (`set`, `advance`), `SystemClock` (drivers only).
- `format` (spec/wire.md §2, §13, all fixed): `FORMAT_VERSION`, `TAG_*`, `MAX_BLOB`, `CHUNK_THRESHOLD`, `PAGE_TARGET`, `CHUNK_MIN`/`CHUNK_MAX`, `CHUNK_MASK_BITS`, `TREE_FANOUT`, `TREE_MAX_LEVEL`, `BLOB_FRAMING_VERSION`, `MAX_CLAIMS`, `*_MS` durations, `MAX_OWNER_DEPTH`, `MAX_VALUE_DEPTH` (64), `MAX_OBJECT_DEPTH` (512), `MAX_VALUE_BYTES`, `MAX_AK_BYTES`, `MAX_URL_BYTES`, `TID_LEN`; `MAX_MESSAGE` (protocol v1) and `TOMBSTONE_LIFETIME_MS` (policy) are not format constants.
- `chunker` (spec/wire.md §6): `GEAR` (lazy, BLAKE3 XOF), `ChunkParams { min, max, mask_bits }` (`FORMAT`; small params for tests), `Chunker::new`, `next_boundary(&[u8]) -> Option<usize>` (incremental, resets itself after a cut), `pending`, `reset`, `chunk_lengths` (one-shot); `PageCutter` for pages: `feed(bytes)` per element piece, `end_element() -> bool` (close the page after this element; resets itself), `pending`.
- `hash`: `hash`, `keyed_hash`, `derive_key`, incremental `Hasher` (keyed, XOF). `kdf` and every purpose string live in osis-crypto.
- `hex`: `encode` (lower case), `decode` (whitespace ignored, `None` on bad input): schema locks, vectors, test constants. `base64url`: unpadded `encode`, strict `decode` (`None` on padding, other characters or nonzero trailing bits): the Tid text form and osis-label's address, link and card text forms.
- Errors: `ErrorClass::{BadInput, Parked, Local}`, trait `Classified { fn class(&self) -> ErrorClass }`, `impl_error!(Enum { Variant => ("fmt", args), .. })` or `impl_error!(Struct, "msg")`.
- `testenv` (doc-hidden, tests only; reads the environment): `known()` (every `OSIS_*` variable, read at run time from core/base/testenv-known.txt, policy.py-checked), `check_known`, `u64_var`, `large_n`/`large` (a `_large` test's per-branch share: a tenth, the full size under `OSIS_FULL=1`), `Seeds::from_env(start_var, seeds_var, default)` (`range`, `overridden`, `announce`, `run`), the seed runner (`run_seeds`, `threads`, `par_map`, `caught`, `checkpoint`: hung-seed detection; notes/testing.md, Seed runners), `visible` (stderr past libtest's capture).

### Integration-test layout
One binary per crate, `tests/it/main.rs` declaring a module per area (`tests/it/<area>.rs`; helpers in `tests/it/common/`), never a new top-level `tests/*.rs` (each is its own ~60 MB executable linking every dependency). main.rs and each module start with `#![allow(clippy::unwrap_used, clippy::expect_used, clippy::panic, clippy::indexing_slicing)]`: clippy.toml's test exemptions cover only `#[test]` functions and `#[cfg(test)]` modules. A module needing a feature gets `#[cfg(feature = "...")]` on its `mod` line.

## osis-schema
- Types (spec/data-model.md §3): `Type` (mirrors §10 `type_expr`: scalars, `Text`, `List`/`Set`/`Map`, `Struct(StructType)`, `Enum(EnumType)`, `Counter`/`Max`/`Min`, `Named(name, args)` incl. `option`/`markdown`/`timestamp`/`duration`, `Param`), `Field`, `Case`.
- `Schema { version, types, aspects: BTreeMap<AK, AspectDef>, doc }`; `AspectDef { ty, retention: Retention, expires, flags: BTreeSet<Flag>, succeeds, doc }`; `Retention { by: PurgeBy, at_least: Bound, at_most: Bound }` (`Default` = untyped: `author_or_admin`, no bounds), `Bound { abs, rel }` (ms), `AspectDefaults { retention, expires }`. Methods: `expand` (named types to a structure), `encoding(&Type) -> Option<Encoding>` (`None` = any), `default_of(&Field)` (declared, or `none` for option), `defaults(ak)`, `view(ak) -> SchemaView`, `validate`, `to_value`/`from_value`/`canonical_bytes`/`hash`.
- `parse(file, src) -> Result<Schema, ParseError>` (file:line:col). `core_schema()`, `core_static()`, `meta_schema()`; `StaticSchema` (embedded source, parsed once).
- Evolution: `check(old, new) -> Vec<Violation { rule: Rule, at }>`, `Lock` (`of`, `to_text`, `parse`), `check_lock(file, lock, allow) -> LockStatus`.
- Typed access (spec/versioning.md §5): `typed_read(schema, v, ty) -> Result<Value, PathError>` (projection: known fields, defaults filled; links pass for large values), `type_at`, `value_at`, `validate_write` (every declared field, nothing undeclared, depth). `Path(Vec<Step>)`, `Step::{Field, Case, Key, Index, Elem}`, `FieldId`, `CaseId`, `p![..]`; `PathError { path, kind: PathErrorKind }` (UnknownCase/UnknownTag parked, Schema local, the rest BadInput).
- Diff: `SchemaView` implements `osis_crdt::View` (project = typed read at the position, `None` = opaque). `large_positions(schema, v, ty) -> Vec<Large { path, map_key }>`: atomic positions above `CHUNK_THRESHOLD`; `link_positions`: positions holding links (chunk repair). Links stand only where the type takes one (`typed.rs` `takes_link`: blob/string, or atomic and not a small type); `misplaced_link` finds others for `Reader::get`/`get_path`, which read them as `Mismatch` before materializing. osis-commit's `check_types` refuses a core-aspect delta that does not fit the core type (`Fragment::fits`: encodings, values by `View::project`, declared enum cases), beside `check_entry_keys`.
- Keys: `trait RawKey { type T; ak, schema, decode, encode; ty, defaults, lifetime, validate }`, implemented by `Ak` (untyped, `T = Value`) and `Aspect<T>` (const, `Aspect::new(ak, &STATIC_SCHEMA)`); `AspectKey: RawKey` marks the typed keys (`Aspect<T>` only). `Codec` (to/from `Value`; std impls incl. `Option` = option enum, `Vec<u8>` = blob, `[u8; N]` fixed blobs, ids, `Role`, `Ts`, `WallMs`), `codec_struct!`, `codec_enum!`, `named_type!` (`TryFrom<&Value>` by the schema's typed read, `From<&T> for Value`).
- `core_types`: Rust types of every core aspect (`Edge`, `Keys`, `Keyset`, `Epoch`, `Secrets`, `SecretBox`, `Label`, `NodeInfo`, `Reach`, `Seen`, `Group`, agility enums, `CreationRecord` codec), constants `TID`..`GROUPS`, `ROLE_CLASS`, `is_role_class`.
- Codegen: `generate(schema, file, src) -> Generated { code, warnings }`, `generate_file(path)` (checks the lock; for build.rs), bin `osis-schema-gen`. Output: `SCHEMA` (a `StaticSchema`), each struct/enum as a `codec_struct!`/`codec_enum!` invocation plus its field/case id module and `named_type!`, one `Aspect` constant per AK.
