# The staged plan for the account redesign
> Summary: The one plan a coordinator builds from for accounts on the ordinary rules, on the built sync unit (a thing's readable closure, so a thing may be carried under several sync IDs): Tess's answers it rests on, the stages in order (what each changes, removes, needs modelled or measured, how it is checked, what it unblocks), why they are ordered as they are, what is deleted when, what every other priority does meanwhile, and the risks with their cheapest early checks.

Designs: notes/account-membership-design.md, notes/write-path-design.md. The sync unit they are stated for is the built one (spec/sync-set.md §2, spec/sync-judgement.md §1-§2); one independent thing per unit was rejected (notes/sync-unit-scope.md). Model: roles-model `paths`, notes/path-model-findings.md. Nothing below is built. Marks: **[checked: ref]** read there for this plan; **[assumed]** taken from a design note or not verified; everything unmarked about the future is the plan.

## Questions for Tess
Answered last (Tess): a delete-key commitment may be reused across an author's blobs within one unit (about 33 B a commit; a node keeping the unit unread can then tell which of its blobs one author can delete, and nothing across units); it is built with the slimming pass after A1 (notes/thing-cost.md, Delete keys per commit). Which unit's commitment a blob carried under several sync IDs takes is that pass's to state.

Answered and planned on (issues/actors-one-mechanism.md Answers): a removal reaches a far thing with that thing's next key rotation and where a node holds both it and a write it judges, never by an errand (eager delivery was drafted and dropped: stage A3); nothing vouches for a role write (issues/role-vouch-contested.md: an unlisted one is dropped and a node that received it tells its user); nothing nobody received is kept; core removes a node when told and never waits, with no hear-out operation tied to removal (a general "wait until every connected node is fully synced" behind a sync button serves a node being retired: UX, later); the last admin is a writer's check only, no rule every node judges, and a timed admin grant does not count as a standing admin for it; a key that signs is a signing key, a value and never a thing, holding an ordinary grant on the thing it signs as and outranking nothing (notes/terms.md; a key that takes a thing back from its admins is parked: issues/recovery-design.md); may-grant is a flag; a write judged invalid is dropped at once as built, nothing kept aside for it and no drop waiting for a complete pass; the dial aspect is core's; a public thing's deposit budget stays open to everyone (keeping the seed from public would mean moving it, not a check in one place). A node keeping units unread may learn which of them share a writer and may know the account it works for (billing, abuse); neither route is hidden, and spec/requirements.md says so (a privacy pass may come someday: issues/sync-units-linked-at-rest.md). Node signers show on public things (a profile's evidence names which signer made each change): accepted with visible mode; a shared signer for a profile comes if and when shared keys are built.

## The order of the account redesign
- **Nothing waits on the sync unit.** Every stage is stated for the built unit, where a thing may be carried under several sync IDs: evidence goes under each sync ID that carries a commit, a removal with it where it is evidence of a held write. Validity is judged from held commits whatever sync ID brought them.
- **S1 is independent**: it fixes work per sync ID held, which every closure pays.
- **Paths (A1) before members (A4).** A node acting as a thing of its own needs a path of at least [A]. With paths first, today's account key actor is simply what a path starts at, so A1 lands with accounts unchanged.
- **Evidence (A2) before the removal's logging (A3)**: a removal's copy under a unit is carried with the evidence that needs it.
- **The ordinary removal complete (A3) before accounts rest on it (A4).** A4 deletes the account's own lists and listings; a removal carried as evidence, whole with its list, must hold first.
- **Public things and cards (A5) before the library (A6)**, so the account functions leave the `osis` crate once, in their final shape.
- A1's one transitional piece: chain certificates certify the stated path instead of searching for one, a narrowing of engine `sync/certified.rs` that A2 deletes.
- **Earliest deletion**: the signing chain at A4. Nothing old is kept beside its replacement inside a stage: formats change in place.

A void lowering costs its check along its author's grant chain, so k void writes at the end of a chain of k grants cost k² setters read (notes/path-model-findings.md 17). Cheapest check: M1 brief 3, before the A1 briefs that build them; then A1 brief 7's count at n and 10n, the void rounds included.
2. **Evidence over a thing under several sync IDs**: modelled (M2): copies placed once when their commit is logged leave a sync ID short where a unit joins or leaves between a commit and its evidence (notes/evidence-model-findings.md 2); re-derived from current holdings at every change they hold, a thing under a root's sync ID and its own judged alike under each. Left: A2 brief 5's sim and differential against the built carriage.
3. **Lazy delivery leaves a removed key's writes showing** in a thing no remaining member writes, at readers served only by stores, until a node holding the removal sees them there. Cheapest check: D2's model of the deposit on sight (notes/write-path-design.md §2, D4); else an issue.
5. **The walk read without trust differs from the trusted one wherever a removal's reach-back drops a write that acted**: a lowering applied at its key keeps its drops and stays applied when a later removal drops it or its author's grant (notes/path-model-findings.md 16), so a node trusting nothing reads otherwise than one trusting the removal, and is shown the removal as a dispute by the widened rule (a lowering whose trust changes the reading; honest histories raise none in the model). Cheapest check: A1 brief 7, counting walks per detection and disputes raised in honest histories of removals.
