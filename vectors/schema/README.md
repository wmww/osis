# Schema vectors
> Summary: Canonical encodings of core aspect values (spec/data-model.md §9). Provisional format until plans/test-infra.md fixes the `vectors/` layout.

`core-types.json`: `vectors[]` of `{name, ak, cbor}`; `cbor` is the hex canonical encoding of a typed write of the core aspect `ak` (every declared field present, `none` spelled out). A conforming implementation decodes each, reads it through the core schema type, and re-encodes the same bytes.

Checked and regenerated by `crates/osis-schema/tests/core_types.rs` (`OSIS_REGEN_VECTORS=1`).
