# A full capped peer keeps an ephemeral entry no node holds
> Summary: `ephemeral::random_window_one_capped_host_large` seed 1811714465 (on main too): the only peer that cannot read the label is full and keeps an ephemeral entry that every holder dropped, so its deletion never came and the stale entry takes room a held entry needs.
> Priority: normal
> Tags: ephemeral, sync, tests

- Repro: `OSIS_EPH_START=1811714465 OSIS_EPH_SEEDS=1 cargo test -p osis-node --test it -- --ignored --exact ephemeral::random_window_one_capped_host_large` (fails on main at b5cfd7f8c and on net-3i alike).
- Failure: "the full host keeps entries [BlobId(d8f25c5e..)] no node holds (cap 4000)". Not traced: which holder dropped the entry without deleting it at the peer (absorbed under a snapshot, expired, forgotten) and why no right holder deleted it there.
- Likely cause (not confirmed for this seed): a forgotten covered entry's delete waits for its cover at the peer (`carried`), and a full peer refuses the cover for the room that entry holds. A superseded entry's author deletes it at a full peer without waiting (spec/sync.md §9); doing the same for covered entries loops (sim `ephemeral_capped` setup 963785799942 seed 963785799952: a co-writer lacking the cover places what it covers into the freed room, the cover is refused again), so a fix here needs a rule that gives the freed room to the cover.
- Candidate single rule (not built or tried): a full host, once room grows, takes the entries it refused before any it has not seen (`unread_room`/`stream_rejoin` pull the refused set first). Then any writer deletes a dropped entry at a full host at once, covered or superseded alike: the cover was refused before the delete freed its room, so it gets that room before a co-writer's new cover or re-placement, and the superseded-only exemption in `carried` goes.
- The same exemption today also covers a commit with one part superseded and another only covered (`MemoryDrop::Superseded` takes both): its covered part can meet the co-writer loop above. Not seen in a run.
