# Moving hosts may move a link's label made on another device
> Summary: `set_hosts` protects K's label with the device-local `x.links`, so another device of the person moving hosts could move a link's label. Seen by reading; a probe's redeem still worked, but the sim host keeps old data, so that does not clear it. Use the seed thing's fields now that any device can list links.
