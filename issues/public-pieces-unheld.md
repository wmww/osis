# The differential's reference reads public things no node can be told of
> Summary: the sync differential's reference counts the public's read on a thing wherever a strong reaches it, but the spec gives that read only where some node reading the referrer holds the thing's public piece (Carriers): a strong held before the thing went public, with no node of the account knowing its sync ID, never learns it; and carriage outlives the carrier. The reference needs carriers of public pieces accumulated over the history.
> Priority: normal
> Tags: sync, tests

The reference (`closure::World::public` in held-model, used by osis-sync `differential`) reads a thing X public at every node whose account's unit a strong reaches it from, or that holds X (sync role, kept unread). The spec gives that read only by a carrier (spec/sync-set.md §2 Public pieces, Carriers) or by the node's own store of X (a node keeping X unread reads it by its head's public entry, spec/sync-opens.md §4 Admissible). Two cases the reference reads that the spec does not give:
- **No carrier, no store**: a strong to X held, with nothing of X held by any node reading the unit, before X is made public. No node knows X's sync ID (sync IDs do not derive from tids), so nothing can tell it; redeeming a link is the way in. The reference needs carriers for public pieces: `(t, x)` counted only where a node reading `t` holds X (as `entry::Net::logged` does for bridges and stubs).
- **Carriage outlives its carrier**: public pieces logged under T while a node held X stay required while a strong reaches X, so a node whose own role on X went keeps reading X by the public (full-size seeds 128, 167, 198 on 8559b6652 under a least-fixpoint carrier rule). Carriers in the reference must accumulate over the history, not be recomputed at the end.

Seeds move with every byte change: replay the full-size class ("node N reads thing N unlike the reference, its value none where the reference's roster lists the public", issues/differential-full-size-classes.md) before trusting these numbers.
