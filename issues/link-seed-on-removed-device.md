# A removed device keeps reading through live links
> Summary: The sharer's link seeds sit in the home group, so a removed (or stolen) device keeps L's seed of every live link: it opens K's head by L's static entry, reads K's newest secret and with it what K holds, past the removal's rotation, until each link is revoked. Same before and after entry boxes carried the earlier secret. `remove_device` could end the person's live links, or say so.
> Tags: security, permissions
