# Settled-history tests' scripted disputes reach nothing
> Summary: two ignored engine `order::` tests play hand-written disputes that no longer reach their case, so they check nothing; rewrite each as a constructed history reaching its case (notes/principles.md, Never pin a seed), or delete it.
> Priority: low
> Tags: engine, tests

- `settled_writers_fetch_what_their_first_side_dropped_before_compacting` (spec/commits.md §5 Invalid): 2 writes G's register while 0 and 2 dispute their roles; writers 0 and 1 drop the write on their first sides; on the walk's side it is valid again and missing, and `settled` fetches before compacting, so a node given the history newest first and the compactions last reads "v5" as the keep-everything node does. The script no longer makes 2's write stand at the keep-everything node (it reads "g"): since `NewTop` things are shared (`share_top`) its `RemoveFlow`/`Demote` targets no longer make that dispute, and its `Undo { by: 0, back: 0 }` is refused.
- `settled_check_spares_things_held_through_unsettled_holds_spec_commits_5` (spec/commits.md §5 Invalid, spec/sync-set.md §2): 2 mints a thing held from G and writes its text while 0 and 2 dispute their roles on G, then leaves G; a node given the history newest first holds the strong missing, and the settled check spares the thing's text. The script's thing is minted, but the keep-everything node holds no text on it (`oracle(..).now` has no `t:text.0` key), so the case is never reached.
