# A late purge of a replacer cannot bring back a body dropped under its cover
> Summary: a body dropped as covered (purge on replace) stays dropped when a purge of the write that replaced it arrives later, so the node reads nothing where a node given the purge first reads the body (spec/commits.md §5 line "A snapshot cannot give back what it replaced" accepts this; Tess's "purging brings back what it replaced" does not). Held-model's late-commit property fails on it; a design question, not a code bug.
> Priority: normal
> Tags: held-model, retention, tests, tess-call

- Found by `props::late_commit_converges_after_repair_large_spec_commits_5` at `OSIS_HELD_START=527365123558 OSIS_HELD_SEEDS=1` (listed in tools/known_failures.txt).
- The case (one aspect, default setting purge on replace): A writes "e"; B resets the aspect; S, a snapshot, copies B's reset (A's "e" is dead in it). The node drops A under S. A purge of B then arrives: S is held as its leftover without B's reset, but still counts as carrying A (spec/permissions.md §5.2: held with its body and valid), so A is never missing again and the node reads nothing. A node given the purge first judges A against the stripped S, finds it uncovered, keeps it and reads "e" (spec/commits.md §5 Purge: a request naming a live write brings back what it replaced).
- Held-model (`model.rs` `stands`) and the engine (`retention::uncover` `carries`) both follow the spec; spec/commits.md §5 Covered ("once dropped, a purge that later falls, or another later judgment that would read the delta alone, restores nothing beyond those copies") accepts the difference.
- No rule fully fixes it: under purge on replace every honest node drops A, so after a late purge of B no node may hold A to fetch. A candidate partial rule ("a snapshot held as its leftover covers and carries nothing": its covered bodies count as never received, and Purge's duty to write a snapshot left whole re-covers them) only helps where a copy survives; tried in held-model alone, it fixes this seed and keeps the engine comparison passing on a hand case, but it was not built in the engine.
- Question for Tess: accept the limit (then the property excepts bodies dropped as covered whose replacer a later purge names, and the spec line stays), or require the late purge to restore A (then purge on replace must keep something of A, e.g. the cover keeping A's writes as dead copies a purge of B revives, a format change).
