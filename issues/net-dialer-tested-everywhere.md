# A reader tests every synced label on every connection a peer dialed
> Summary: `add_new_labels` starts every label this node syncs on each connection a peer dialed (no listing check, the dialer's listening key being unknown), so any dialer whose filter shows L's sync-key beacon (built from the public sync key) pulls L's ciphertext, against the interim "readers serve L to a peer that cannot read it only where it is listed for L (3h2 to 6c)"; and every such connection, thin clients' included, holds a `LabelAt` per synced label, retested each `resync_ms`.
> Priority: normal
> Tags: security, node, tess-call

- **Exposure**: the reader's sync-key Hit (`shared_test`, `peer_creds` over `Conn::labels`) goes where the dialer's filter shows the beacon; the dialer needs only L and the sync public key for the beacon and the reply tag, never the sync secret. So a node not listed for L that knows L's current sync public key (a host dropped from `label.0` before the next sync-key rotation, an ex-reader) dials any reader and pulls L's stream: ciphertext, sizes, timing, and that the reader syncs L. issues/net-one-peer.md (Pull, not upload; Interim states) still says readers serve so only to a listed peer. Either the interim ends here (state it, and that 6c's rule decides later), or such a dialer proves the sync secret (an open signature from the dialer too: a spec change) or is not tested until 6c (and `unread::a_peer_that_cannot_read_pulls_from_a_reader_it_dialed_spec_sync_10` waits for 6c).
- **Cost**: a `LabelAt` per synced label on every connection a peer dialed, client-port sessions included (they never begin a shared set, but the labels start at `conn_start`), so `next_wake` and the timers walk connections times labels each step; a label the dialer does not hold stays `Testing` and `rewalk` retests it every `resync_ms` (`shared_test` builds its sync credential each time). Before, a served connection had no per-label state. Start labels on such a connection only once its shared set began, or test the synced labels' sync keys against the filter without per-label state there.
