# A leaver's own history entry can still cover its own departure
> Summary: The departs-mark rule (`NamesHeld::departed`) closes only marks. A leaving writer can list its own self-removal by key in a backdated entry, and a node holding admin on A only through group M can demote M by an explicit demotion whose rotation it made and whose mark is met. Both leave the leaver reading new content. A rule keyed on the entry's author, not on the mark, would cover all shapes.
> Tags: security, keys, tests

Repros (`#[ignore]`d) in core/engine/src/rotation/tests_departs.rs:
- `repro_self_removal_listed_by_backdated_entry`: W self-removes at `ts`, then writes a commit backdated before `ts` (W was still a writer there, so it is valid) putting an entry at the current read epoch whose `list` names the self-removal by key. Names in `list` are met when the commit is applied (spec/crypto.md §4, Met, first bullet); no rule asks who wrote the entry. The epoch covers W's departure and nobody rotates.
- `repro_holder_actor_demoted_by_its_own_admin`: group M holds admin on A; P1 (M's owner) holds admin on A only through M. P1 demotes M to write as an explicit demotion (perm judges it one: edge-admin authority through M counts, spec/permissions.md §2 "through X included"), rotating admin and read and boxing M at read, which shows M (Possession Authority holds). The mark is met (a rotation commit, no self-removal). P1 made the new admin secret and holds only write after; the owner keeps that epoch.

Direction (unverified): an entry's names cover no departure that lowers its own author's role on A (holders for keys, through holder actors included). This subsumes the mark rule's self-removal and `keys.0` clauses (the guessed-mark case is the leaver's own entry too) and needs the writer of each live history entry. The holder-actor shape also goes away if the perm judge stops counting authority through the holder X for a self-removal (issues/self-removal-through-holder-disagrees.md), but the list shape does not. The spec's Limit line (spec/crypto.md §4, Met: "any departure it holds but its own") is false until this is fixed.
