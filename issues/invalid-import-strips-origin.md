# An invalid import on a copy strips every held copy of its origins' writes
> Summary: `atomic::invalid_of` turns each invalid import into `Owned::Commit(C)` per origin C, which strips C's re-sourced writes on that aspect from every body, the honest move's valid import and snapshots included; a reader (or a demoted writer) of a moved thing can erase its imported history with one import. Also the claim for carried writes (`Core::authors`) is the least held import, valid or not.
> Tags: security, node, validity

Repro (ignored test): `cargo test --workspace --test it walks::invalid_reimport_changes_nothing_spec_perm_7 -- --ignored` (a writer demoted to reader on the copy, unaware, imports t again; the copy's `/t/reg` and `/t/tags` vanish at a node holding the demotion). On main before the double-import branch as well (`invalid_of` unchanged). Breaks spec/requirements.md "malicious readers can only waste storage".

Second path, same root: `Core::authors` takes the least held import by (`ts`, ID) whatever its validity (spec/permissions.md §7), so an invalid import with a small `ts` re-attributes the carried `Commit(C)` writes of snapshots on aspects no held import has to its author at its `ts`; judged invalid there, they vanish.

Needed semantics: a `Commit(C)` write on (N, ak) is valid iff some valid owner holding it is (C itself commit-form with ak, or a valid import of C with ak); an invalid co-owner strips only the dots no valid owner holds (it may carry forged dots under `Commit(C)`). That needs per import part the set of `Commit(C)` counters it holds (an index written with the commit, like `EdgeParts`), per-body stripping in rebuild, and a rebuild instead of the in-place un-merge when an import with a valid co-owner flips. The claim should be the least valid import, re-derived in `rejudge_all` after validity flags change (no cycle: imports never carry membership-class aspects), falling back to the least snapshot entry. Alternatively a structural rule that only the copy's creator may import into it, if the receiver can learn the creator.
