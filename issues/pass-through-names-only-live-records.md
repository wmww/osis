# A chain passes an invalid rotation only while one of its box records is still live
> Summary: spec/crypto.md §4 lets a rotation's chain pass an invalid rotation commit G of s only when the superseding commit's removal at s names G by dot; once grants have re-written every box G made at s (remove + put), the removal names only the grants, the chain stops there, and the 51-shaped leak (a valid rotation never established while its box removals apply) comes back.
> Tags: security, keys, engine

Found reviewing epoch-chain (not reproduced end to end). Settled (spec/crypto.md §4): for each superseded s, s established, or no valid claim of s held and the removed box's record names a held invalid, settled rotation commit of s. The record's dot names the commit that wrote the live box record at removal time. A grant (`box_holder`, `put_secrets`: remove + put) to a holder already boxed at s re-writes that record, so after grants to every holder G boxed at s (promotions, re-grants), a later rotation C removing the boxes at s names only the grant commits. Where G is invalid (its author demoted concurrently, the grants and C made by nodes not yet holding the demotion), C never settles, nor anything after it, while C's removals apply: an epoch C removed every box at that the node counts current covers every departure (the shape of `rotation::tests::forks_with_departures` seed 51 before epoch-chain). On main before epoch-chain such a chain never passed an invalid commit at all, so this is no regression, only the case the fix does not reach.

Reachability is narrow: every recipient of G at s, G's author included, must be re-granted at s before C. A re-seal never re-writes a live box (it boxes holders lacking one).

Possible fixes: accept a named commit X when X is a claim of s, or X's own removal at the same box key names (transitively) a claim of s, all held; or let a grant keep the box record (write into it) instead of remove + put. Either needs the boxing rules' reason for remove + put kept (a holder never gets a write into an entry it never got).
