# The models judge lists by per-thing leaves
> Summary: A lowering's list names each commit whole (notes/a1-spec/README.md Open 25), but roles-model, held-model and osis-perm's tests still cut lists into per-thing leaves that a reader may see apart; making them whole changes model verdicts, so it waits on a model change.
> Priority: normal
> Tags: permissions, tests

The engine builds whole lists only (osis-perm `paths::List::whole`, from `timeline`). Everything else that builds or reads leaves:
- **roles-model `paths`**: `Kind::Edge::frontier` is `BTreeMap<Thing, Set>`, cut by each listed part's thing (`World::cut`, `World::edge`); `in_frontier`/`in_leaves` name a part only from the leaf of its own thing, so a split commit listed in one leaf keeps its other parts unnamed. `View::leaves` lets a node see only some leaves: the story's views (`story::view_choosing`, `leaves`: the things a node syncs, plus with `Rules::evidence_leaves` those a held edge write is on), and hand tests with `leaves: Some(..)` in `paths/tests.rs` (`a_removal_logged_only_where_the_node_wrote_leaves_a_window`, `reader_of_t1`).
- **held-model `evidence`**: the control `Lists::Unit` (finding 4, `f4_a_reader_needs_the_leaf_of_each_evidence_copy`) passes a unit's things as `View::leaves`; the `wide` generator lists split commits per leaf, and finding 24 (`spec_gaps::gaps_a_list_entry_names_its_part_on_its_leafs_thing_alone`) is a world whose verdict turns on it.
- **osis-perm**: `List::new` (per-thing entries), `List::names(commit, on)`, `List::keys` (`Option<Tid>` per entry) and `content::Facts::named`, keyed by (commit, Option<Tid>). Built per thing only by tests: the `paths` differential (`tests/it/paths/mod.rs`, from the model's frontier), `shapes.rs`, `counts.rs`; osis-engine tests `role_paths.rs` and `evidence/walk.rs`.

**What making them whole takes.** roles-model's frontier becomes a set of commits naming each whole (by commit ID, a cover by what it carries); `View::leaves` and `Rules::evidence_leaves` go (whoever holds a lowering reads its whole list: notes/write-path-design.md §2 E4); the story properties re-run and every moved verdict read; finding 24 and `Lists::Unit` re-read (the first moot under a whole list, the second a control of something that cannot happen). Then osis-perm's `List` is a `Frontier`, `Facts::named` keyed by commit, and the tests build whole lists. After it run osis-perm `paths::` and osis-engine `evidence::` differentials.
