# Sync differential: failure classes beyond the gate's seeds
> Summary: the sync differential at full size (38 of 200 failing on b21ba1c7f, 32 with the reference's public pieces logged over the history; the largest class a node keeping a thing unread behind its readers) and at small size beyond the gate's seeds: the remaining classes by first panic, with shrunk scripts, each to turn into a hand test.
> Priority: normal
> Tags: sync, engine, tests

Seeds move whenever commit bytes change: work from scripts, and turn each class into a hand-written test (notes/principles.md, Never pin a seed). Replay: `OSIS_FULL=1 OSIS_SYNC_START=<n> OSIS_SYNC_SEEDS=1`; run the 200 seeds as four `tools/heavy` holds of 50. A script replays over many worlds in a scratch test (`differential::worlds("scratch", |_| vec![..])`); at small size most of the scripts below fail at seed 0 too (`holds_on(0, 2, 3, ..)`, full size `holds_on(0, 3, 4, ..)`).

- **Seeds 0..150 at full size on 6167cf270** (one hold, about 5,100 CPU-s): 22 fail: reads unlike the reference 15, 23, 70, 102, 123, 128; unread a step behind 32, 50, 52, 80, 99, 101, 149; sync set unlike the model 10, 38, 78; must-hold a caught-up reader lacks 35, 48, 84; parked 26; must-hold with no entry 121; storm 108. The secrets-index class is gone (a roles secret kept beside its checked secret only when the history entry came second: `RoleEpochs::set_roles`).

Spec: sync-judgement.md §4 Writer says a writer stamps for the source's head what it logs there, which one entry per blob cannot do for two sources at two heads. Fix candidates: a writer deposits (or logs a fresh copy stamped for that head) where its stamp is not under the source's head, judged per source head; or a step needs only what its parent's epochs did not. - **A debug check feeding its own settle** (latent hazard): `Engine::role_duty_due` checks itself against `rotated_already` in debug builds, a run rolled back; the rollback moves the stamps it undid, so the duty's key is due again at once, and the rolled-back writes (a grant fire owed) reach the fires feed.
