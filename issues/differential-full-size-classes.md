# Sync differential: failure classes beyond the gate's seeds
> Summary: the sync differential on held-model's stub closure (`Rule::BUILT`) at full size: 20 of 100 seeds fail, by class with each shrunk script (most involve the public's role; the sync ID fork is a design question), and the gate seed tools/known_failures.txt lists. Each class to become a hand-written test.
> Priority: normal
> Tags: sync, engine, tests

Seeds move whenever commit bytes or delivery order change: work from the scripts, and turn each class into a hand-written test (notes/principles.md, Never pin a seed). Replay a seed: `OSIS_FULL=1 OSIS_SYNC_START=<n> OSIS_SYNC_SEEDS=1 cargo test -p osis-sync --test it -- --ignored --exact differential::histories_hold_their_closure_plain`; the 100 run in one `tools/heavy` hold (about 200 s wall). A failing check prints the history as a script; `OSIS_SYNC_SHRINK=1` shrinks it (several shrinks side by side take a hold: run copies of the built binary in one `tools/heavy` script). A script replays in a scratch test (`differential::played_on(0, 3, 4, &script, String::new(), false)` then `history::check`, full size). The scripts below are shrunk from their seeds; those marked "world 0" also fail there.

## Sync ID fork (design question)
Two nodes of one account, apart, each make a dependent thing X independent (each by a grant, or one by a grant and one by the public's), so each records its own sync ID (spec/sync-ids.md §2: both stand, X synced through the greatest). A grantee told on the lesser side's sync ID S1 holds S1 alone; once its granter syncs X through S2, nobody serves S1 to it. Hand case: `differential::a_grantee_on_a_sync_id_forks_lesser_side_follows_the_greater_*` (ignored). Seeds 0, 5 and 53 shrank to it before the last rerun (not shrunk again), as does the gate seed. Simplest option seen: a node reading X keeps syncing every sync ID of X it owns (as a node keeping X unread already does); unchecked that the grantee then owns S2 (spec/sync-ids.md §4 Owner).

## The public's role (most classes)
- **Carriage by the public's sync its heads list** (31, 84; hand case `differential::a_removed_reader_keeps_the_publics_sync_secret_*`, ignored). 31: `New(2), Give(2, 0, Node(0), Reads), Give(2, 0, Node(1), Reads), Run, Lossy(..), Revoke(2, 0, Node(1)), Give(2, 0, Public, Syncs), Strong(0, None, 0), Revoke(2, 0, Node(0))`. `edge_carries` counts the public's sync by its grant alone; the removed reader knows it only by the heads listing the public (`public_listed`), so its account's strong enters nothing and it holds the thing as its signal's stub where the model keeps it unread. Counting the public by both (`keyed_role_now(PUBLIC).max(public_listed)`, with `enter` giving read where the listing gives read) fixes the hand case but breaks `New(2) x4, Give(2, 3, Public, Reads), Redeem(0, 3)` (world 0): the redeemer enters by the listing, read, and never holds the public's grant commit (its roster lacks the public).
- **Reads unlike the reference, a reader by the public also granted** (world 0 unless noted): 14 `New(3), Run, Give(3, 0, Public, Reads), Redeem(2, 0), Give(0, 0, Node(2), Syncs)`; 70 `New(3), New(0), Run, Give(3, 1, Public, Reads), Give(0, 1, Node(2), Syncs), Strong(2, None, 1)` (passes on world 0); 85 `New(2), Give(2, 0, Public, Syncs), Give(2, 0, Node(0), Reads), Strong(3, None, 0)`.
- **Stub, the model Unread** (2): `New(3), New(2), New(2), Give(2, 1, Public, Syncs), New(3), New(0), Run, Strong(3, Some(4), 1), Give(2, 1, Node(0), Syncs)`.
- **Stub, the model None** (45): `New(0), New(0), Inbox(0, Some(1)), Give(0, 1, Node(2), Reads), New(1), Strong(2, None, 1), Give(1, 2, Public, Reads), Run, Give(1, 2, Node(0), Syncs)`: node 2 reads node 0's inbox and thing 2 is public; 86 unshrunk.
- **Lowered with the public** (12; hand cases `differential::a_node_lowered_with_the_public_*`, three, ignored): 12 `New(1), Give(1, 0, Node(2), Syncs), Run, Give(1, 0, Public, Reads), Strong(2, None, 0), Revoke(1, 0, Node(2)), Lower(1, 0, Public, Syncs)`. The lowered node keeps the thing unread with no store path (no step registered with it), its readers' head 4 deep; in 12 it still holds S as read, so a body a reader must hold never reaches it.
