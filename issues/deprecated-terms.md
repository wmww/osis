# Deprecated terms and concepts
> Summary: The one registry of old words and concepts still in the repo (Tess: each is gone or listed here, marked deprecated with what removing it takes). Per row: the term, where it remains, why, what removing takes. Words are fixed by spec/requirements.md Terms and notes/api.md Rules; a row goes when its last use does.
> Priority: low
> Tags: naming

Everything below is **deprecated**: never build on it, never add a use. Where a row points to another issue, that issue owns the work; this one only keeps the list whole. Not counted: `docs/` (refreshed on request), history logs (notes/complaints/), and words with another, current sense (below the table).

| Term or concept | Where it remains | Why | Removing takes |
|---|---|---|---|
| **host**, **hosts** (a node keeping data unread) | the dogfood tooling: `tools/dogfood-member.sh host` and its unit names (`osis-dogfood-host-*`), notes/dogfood.md, notes/handoff.md; the TLA models (row below) | code, spec and notes say "a node keeping S unread", "peer", "source" (`tools/policy.py` `old_words` keeps it out of code) | the dogfood scripts and units at the next dogfood rebuild (notes/dogfood.md) |
| **box**, **boxes**, **serving node** in the node sense, and any word naming a kind of node by what it can read ("blind node", "storage node", "keeper" for a node) | none left in code, spec or notes (the Serving API's own name stays until issues/sync-rewrite.md 6b replaces admission) | Tess: "box" is the old host renamed; whether a node can read data is a property of the pair (node, sync ID), never of the node, and every node serves. Say "a node (peer) that cannot read L", "the node keeping L unread for account A" | keep out |
| **admission** of what a node keeps unread: `host^.0` `admit`, keep lists | the running dogfood node, started at an older pin (`--admit open`) | code, spec and notes are done: a node keeps exactly the sync IDs of its synced group's closure | the dogfood node at its next pin (notes/dogfood.md) |
| **placed** in the sync sense | engine `sync/certified.rs` (`Placed`: a piece's certificates going under read things) | code elsewhere, spec and notes say **logged**, **held at**, **held elsewhere** | a rename of `Placed` and its comments when certified.rs is next touched |
| **upload** for putting an entry in the own store or at a peer | spec/requirements.md "re-upload" (user level, kept); the TLA models (row below) | code, spec and notes are done (`old_words` keeps it out of code) | requirements wording proposed to Tess (issues/sync-tess-calls.md) |
| The TLA models' old vocabulary: **label**, **host** (`atHost`, `MaxHost`, `HostBranch`, `CipherHost`), **upload** (`Upload`, `UploadRot`), **device** in the node sense | core/test/tla: `sync/` (SyncConvergence, MC), `sides/` (Sides, MC, cfgs, matrix.sh), `rotation/` (Rotation, Depth0, Depth0MC, Account, Joint, JointRule, Reseal, cfgs), `net/NetBlind.tla`, their READMEs, ASSUMPTIONS and AMBIGUITIES, `run.sh` | a model rename means rerunning TLC | the models in one pass with a TLC rerun (app UI text may say device: Tess's Terms) |
| Spec rule words where a role is meant: **edge**, **rights**, **demotion**, **revocation**; one of **part** / **delta** | spec throughout; engine `Edge`, perm | concept changes listed with the peer work | issues/sync-rewrite.md |
| Engine names under the API's: `Written`, `Mutation::expires` per aspect, `CommitKind` beneath the API's, `Time` as `WallMs` | engine | the API has one word; the engine's is older | issues/sync-rewrite.md |

Not old terms (other senses, kept): **placement** of sequence elements (osis-crdt, the paged store: positions in a list or text); **device** as storage or the machine an attacker holds (store `Device`, "an attacker holding the device"); the app's **Person** kind, an address-book contact; `on_change`/`Change<T>` (a value changing, notes/api.md); **server** for a chat community (notes/realms.md) and in third-party names; **blind** as the header's 16 random bytes (spec/crypto.md §7). **box** in the encryption sense (a sealed or symmetric box, "boxed to" an actor: spec/crypto.md, spec/wire.md §7) and for a machine ("this box", notes/build.md), and outpost's **box** (notes/outpost.md). **label** for a UI text label (kit, app, Masonry) and a run's or job's name in test tooling (`testenv`, `costs`, the roles-model's checks). **batch** for a group of store writes, records or events (osis-store, a pull reply). **ended**, **ending** for what has a span: a grant's or edge's `until`, a link, a stream, a pass, a connection, a subscription, a shared-set member (a thing is never ended but **destroyed**; `tools/policy.py` `ended_names` keeps the old sense out of code).
