# A stale box two levels down blocks only sealing, not writing under an existing epoch
> Summary: A writer of G holding M's knowing keyset, with G's current epoch boxing A at an epoch whose box (or box record) to M names M's superseded keyset, keeps writing under G's epoch: the party removed from M opens it through A until G rotates for another reason or A's rotator comes back. The model (Depth0 `PfJudge`, `NoLeakDeep`) blocks that epoch; the build judges such a stale box only in Seal (`Walk::Seal`).
> Priority: normal
> Tags: security, engine
