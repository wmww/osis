# Gone writes: what is left of the rewrite
> Summary: spec/crdt.md §4.7 (an expired or purged write has no effect on the read) is built in crdt-model, osis-crdt, held-model and the engine's join and rebuild, but the engine still has ~28 tests asserting the value-less meaning, expiry rebuilds its aspect (against Scale), and the value-less representation and wire forms are still in code.
> Priority: normal
> Tags: crdt, engine, tests

Branch `mizzen-purge-no-effect`. Built: `Fragment::remove_gone` (crdt-model `Frag::remove_gone`) removes a gone delta's writes from each body before it joins; the engine strips each piece in `apply::rebuild` and each joining delta (`strip_valueless`), expiry always rebuilds (the in-place strip is deleted), a snapshot carries no expiring write, an expiring commit is no whole replace, a purged commit held only as leftovers is forgettable at once. Hand tests: order `a_purged_write_reads_as_never_held_whatever_reaches_first_spec_crdt_4_7` (the 5-step history, m4 in both orders), `expired_part_given_before_its_record_reads_what_came_before_spec_crdt_4_7`; the order oracle no longer excuses aspects an expired commit lists.

Left:
- **Tests still asserting the old meaning** (restate to the rule, most read the replaced value or lose others' nested writes): engine lib `pages::tests::seq_placement_differential_text_spec_crdt_6`, `retention::tests::a_purged_leftover_goes_at_once_spec_commits_5`, `undo::tests::pre_state_at_a_reset_gone_or_invalid`; engine it `resnapshot::{owed_resnapshot_survives_a_stop, owed_resnapshot_whichever_comes_first, purged_secret_reads_nothing_whatever_reaches_first}`, `order::{register_deaths_purged_killer, expired_late_part_joins_valueless, cover_leftover_outlives_its_cover, purged_covered_leftover_survives_unmerge, map_death_across_key_erased_record, key_erased_copy_keeps_record_before_expiry}`, `review::expiring_commit_applies_without_missing_delta`, `shred::{edit_into_expiring_entry_keeps_its_expiry, reaction_outlives_expiring_message, purge_spares_other_values_of_a_carrier, purge_leaves_later_edits_own_key, junk_beside_a_part_past_expiry_raises_no_flag, undelete_chars_are_their_own_values, waiting_snapshot_drops_a_purged_copy, past_expiry_and_purge_alike, purge_of_a_waiting_part_reads_alike, removed_map_key_gone_after_purge, undo_copying_two_expiries_waits}`, `validity::a_purge_request_is_judged_alike_in_both_path_forms`, `waits::{list_element_expiry_in_any_order, list_element_overwritten_stays_past_expiry, list_element_in_snapshot_before_expiry_reads_alike, expired_list_element_survives_unmerge, snapshot_past_expiry_beside_body, purged_list_element_keeps_edit_in_any_order, expired_entry_keeps_nested_write_alike}`, `expiry_model::expiry_takes_only_its_commits_values`. Check each: `past_expiry_and_purge_alike`, `snapshot_past_expiry_beside_body`, `expiry_model` and `pages` fail on more than a read.
- **Scale**: `scale::expiry_is_flat_spec_crdt_4_7` fails: an expiry rebuilds its aspect, O(bodies). Removing in place equals the rebuild iff the gone delta superseded nothing a held body holds; deciding that needs the held writes' killers (the dating index), not the state. Design, don't loosen the test.
- **Representation**: nothing makes a value-less write now, but osis-crdt and crdt-model still decode, join and encode them (`[Stamp, false]` `W`, `[0, R, Stamp]`, the list `Creation` `false` marker, key-erased records holding value-less writes, `Meta::w_valueless`, `SeqElem::valueless`, `valueless_dots`, `each_valued`), the engine's `Carried` keeps valued and value-less spans and `covered_join` a value-less check, and `ix.valueless` is named for the old meaning (it is the gone list). spec/crdt.md §3.2 no longer has the forms: delete them (decoder rejects), rename the list, drop `Carried`'s valued/value-less spans.
- **Leftovers**: a gone content delta still gets an empty leftover row (`Hold::Leftover`); only a snapshot needs one (its body without the gone copies). Make a gone delta a dropped part.
- notes/crdt.md still describes key erasure under expiry (map entry records, copy order) and the purge re-snapshot duty (spec/commits.md §5 Purge) may no longer be needed: check what it still serves.
- spec/requirements.md Decentralization's arrival-order limit for expiring edits no longer describes a divergence: Tess's call whether to drop it.
