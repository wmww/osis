# Gone writes: what is left of the rewrite
> Summary: spec/crdt.md §4.7 (an expired or purged write has no effect on the read) is built and tested; left: expiry rebuilds its aspect (against Scale, waits on the dating index), the engine's value-less spans and list naming, register/case `Option` values and keyless-creation decoding in osis-crdt, two stale notes, and Tess's call on a requirements line.
> Priority: normal
> Tags: crdt, engine

Built: a gone delta's writes are removed from each body before it joins (`Fragment::remove_gone`, crdt-model `Frag::remove_gone`); a gone delta left with no write is dropped (`DropFor::Other`), as is an expiring snapshot at its T, so no leftover row is kept for either; a purged whole replace is no own replace (what it covered is missing again); no wire form or state of osis-crdt or crdt-model holds a value-less `W`, list creation, register or case write (decoders reject them).

Left:
- **Scale**: `scale::expiry_is_flat_spec_crdt_4_7` fails: an expiry rebuilds its aspect, O(bodies). Removing in place equals the rebuild iff the gone delta superseded nothing a held body holds; deciding that needs the held writes' killers (the dating index, branch `mizzen-dating-redesign`), not the state. Build in-place removal on that index once it lands; don't loosen the test.
- **Engine value-less spans**: `snapshot::Carried` keeps valued and value-less spans, `covered_join`/`covered` and `names::carried` ask `Fragment::valueless_dots`, which no decoded data can feed now (only a keyless map record with a creation, or a text creation without its char, could). Drop the value-less spans, `holds_valueless`, `valueless_dots` (marked Interim), and rename `ix.valueless` / `records::VALUELESS` / `list_valueless` / `strip_valueless` / `Hold::Leftover::valued` / `Meta::bare` for what they are (the gone list; a leftover is now only a snapshot's or a delta's carrying copies).
- **osis-crdt types**: `RegWrite::value` and `CaseWrite::case` are still `Option` (only `None` from hand-built tests); make them plain. Decide whether a keyless map record may carry a creation or a fragment (spec/crdt.md §3.2 `Entry` still allows the fragment); if not, reject on decode in both implementations.
- **Notes**: notes/expiry-creation-design.md and notes/ephemeral.md (Ephemeral expiry is durable expiry) still describe value-less leftovers; rewrite to the gone-write rule. notes/crdt.md's map-entry text on key erasure under expiry (`Map::record_frag`, "expiry erases it") describes what nothing does now.
- **Purge re-snapshot** (spec/commits.md §5 Purge, `purge::owe_resnapshot`): still needed. A node that dropped a body as covered under a snapshot carrying the purged write cannot bring back what the purged write replaced (spec/commits.md §5: a snapshot cannot give back what it replaced); a writer still holding the replaced body re-snapshots and so carries it to them, and its snapshot lets holders drop the replaced body again. So the duty now serves "purging brings back what it replaced" at nodes that compacted, not hiding values.
- spec/requirements.md Decentralization's arrival-order limit for expiring edits no longer describes a divergence: Tess's call whether to drop it.
