# The node root is not kept local
> Summary: spec/sync-set.md §1 says the node root is local with no sync ID, but commits written beside shared things carry it: (1) a thing minted with admin the node root (osis `create`, whose account root is the node root), made independent for a grant, makes the root independent too (spec/permissions.md §3 holder actors); (2) a commit writing the root's `holds.0` beside a shared thing (`Engine::new_thing`'s holding strong, the sync harness's making) travels with that thing: its root section is sealed under the thing's sync ID (a `dw/` row of the root nothing lets go), and a receiver, never holding the root's record, judges the commit pending on it (`UnknownCreated` of the root) instead of applying its other parts. Either nothing shared is written beside the root (piece 2: things made in the account) or the spec says what a receiver does with a part on a thing whose record never travels.
