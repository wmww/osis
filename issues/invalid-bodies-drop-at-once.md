# Drop invalid bodies at once
> Summary: Plan (Tess: dropping and refetching is fine): a body judged invalid drops at the end of the transaction that judged it, except the node's own commits (their author shows and resends rejected writes); one turning valid again (re-grant, late addendum) is refetched from any holder, lost when none has it, nodes agreeing. An invalid write contributes nothing to the state, so this fits the retention principle. Tried once on the addenda branch; what it needs is below.
> Priority: normal
> Tags: engine, retention, permissions

1. **Fix first, on its own**: dropping must equal rebuilding. Today an aspect whose only delta arrived invalid and was dropped reads `None`, while the same held set reached by the delta arriving valid then turning invalid reads `Some(List([]))` (the un-merge leaves the empty container).
