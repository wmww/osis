# Caret nearly invisible on the default light theme
> Summary: A text field's caret is drawn in `look.accent`, which on the default theme's light background is nearly invisible (seen on the emulator); touch selection handles use the selection colour for that reason. The caret and handles should take a colour that passes the theme's readability checks (libs/kit tests `theme`) on the field's background.
