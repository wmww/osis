# A voucher holds admin by a share only a vouch removes
> Summary: A vouch counts by its voucher's admin in the first walk (every vouch unread), where a lowering kept only by another vouch is dropped: a removed party keeping admin on a holder thing makes a key admin of it and vouches by a share of that holder it removed itself, keeping a backdated write the reading gives no right to. Today's engine and the stated-path design both have it.
> Priority: normal
> Tags: perm, security

**Smallest world** (notes/path-model-findings.md 39; roles-model `repro_a_voucher_holds_admin_by_a_share_only_a_vouch_removes`, engine `apply::tests_vouches::repro_a_voucher_holds_admin_by_a_share_only_a_vouch_removes_spec_perm_5_1`, both ignored and failing): team A2 is admin on T1; X is admin of A2 and (directly or through A) of T1. X removes A2 from T1; only B, an admin of T1, receives it. H removes X without listing it, and B vouches for X's removal of A2. X, still an admin of A2, makes Z an admin of A2, backdates a grant of write on T1 to Z, and Z vouches for it on T1. In the first walk no vouch counts, so H's removal drops X's removal of A2; A2 is admin on T1 there, so Z's vouch applies and its entry counts. In the reading B's vouch keeps the removal of A2, so Z never held admin on T1, yet Z's grant stands. Without Z's vouch it falls.

**Where**: the stated-path draft (notes/a1-spec/permissions.md §5.1 Vouches, First walk; `osis_perm::paths`, which agrees with the model) and today's rule ("W could write c" judged in the first walk, spec/permissions.md §5.1 Vouches): the engine test fails on main.

**Why it is not trivial**: reading the voucher's authority in the walk its vouch changes has no fixpoint (finding 2: B vouching for X's demotion of B counts only while the demotion does not stand). Finding 3 (a holder kept by a vouch vouches for nothing) is the mirror case and accepted.

**Fix to model next** (each vouch judged by every other vouch, never by its own): C0 = the entries counting by the first walk (today's set); C(k+1) = the entries of C(k) whose vouch V applies, and whose removal still applies as a lowering, in the walk where C(k) without V's own entries counts; the timeline reads the limit. It only removes entries, so it ends within |C0| rounds, the same for every arrival order, a function of the held set (rare path: a walk per counting vouch per round). It closes 39 (Z falls: B's entry removes A2's share), keeps finding 2's world (B's vouch is judged without its own entry, so B stays admin) and adds nothing to finding 3. Two vouches each keeping the removal of the other's share both fall (conservative). Rejected: (i) the voucher must hold admin in the timeline itself (the limit of C(k) read with V's own entries): finding 2's honest demotion falls, failing the story's liveness (x_role 1); (ii) no vouch counts whose path rests on an edge R's drops restored: K, whose share X removed before the theft and R restored, could not vouch for X's honest writes it received, a liveness loss for no safety gain where nobody keeps X's removal.
